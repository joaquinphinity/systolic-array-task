Implement a 2x2 systolic array module in sources/systolic_array_2x2.sv.

The systolic array is a core building block for TPU-style matrix multiplication accelerators. You need to instantiate 4 MAC Processing Elements (mac_pe) and wire them together.

## Your Task

Complete the implementation of `systolic_array_2x2` in `sources/systolic_array_2x2.sv`.

The MAC PE module (`mac_pe`) is already provided in `sources/mac_pe.sv` - you should use it as-is.

## Requirements

1. **Instantiate 4 mac_pe modules** in a 2x2 grid:
   - pe_00 (row 0, column 0)
   - pe_01 (row 0, column 1)
   - pe_10 (row 1, column 0)
   - pe_11 (row 1, column 1)

2. **Wire horizontal connections** (activation data flows left to right):
   - Row 0: act_row0_in → pe_00 → pe_01 → act_row0_out
   - Row 1: act_row1_in → pe_10 → pe_11 → act_row1_out

3. **Wire vertical connections** (partial sums flow top to bottom):
   - Column 0: psum_col0_in → pe_00 → pe_10 → psum_col0_out
   - Column 1: psum_col1_in → pe_01 → pe_11 → psum_col1_out

4. **Implement weight loading logic**:
   - When weight_col_sel=0: route weight_load to column 0 PEs only
   - When weight_col_sel=1: route weight_load to column 1 PEs only
   - weight_row0_data goes to the row 0 PE of the selected column
   - weight_row1_data goes to the row 1 PE of the selected column

5. **Broadcast control signals**:
   - enable goes to all PEs
   - weight_switch goes to all PEs

## Interface Summary

Inputs:
- clk, rst_n: Clock and active-low reset
- enable: Enable computation
- weight_load: Load weight into shadow buffer
- weight_switch: Switch to new weights
- weight_col_sel: Select column for weight loading (0 or 1)
- weight_row0_data[7:0]: Weight data for row 0
- weight_row1_data[7:0]: Weight data for row 1
- act_row0_in[7:0], act_row1_in[7:0]: Activation inputs
- psum_col0_in[31:0], psum_col1_in[31:0]: Partial sum inputs

Outputs:
- act_row0_out[7:0], act_row1_out[7:0]: Activation outputs
- psum_col0_out[31:0], psum_col1_out[31:0]: Partial sum outputs
