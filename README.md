# 4x4 Systolic Array Task

This task involves implementing a 4x4 systolic array for matrix multiplication, a core building block of TPU-style accelerators.

## Task Overview

* **Type**: RTL Design (Module Integration)
* **Difficulty**: Hard
* **Files to implement**: `sources/systolic_array_4x4.sv`
* **Context provided**: `sources/mac_pe.sv` (MAC Processing Element)

## What You Need to Do

Implement a 4x4 systolic array that instantiates 16 MAC Processing Elements and wires them together for matrix multiplication.

See `docs/Specification.md` for detailed requirements and `prompt.txt` for the task description.
